🔔 毎月自動チェック設定
GitHubに作品リストを同期すると、毎月1日に新刊情報を自動でチェックして GitHubのIssueで通知します（メールにも届きます）。

同期にはGitHub Personal Access Token（PAT）が必要です。
📖 PATの取得方法
1. GitHub → 右上アイコン → Settings
2. 左メニュー一番下「Developer settings」
3. Personal access tokens → Tokens (classic)
4. Generate new token (classic)
5. Note に「新刊トラッカー」と入力
6. Expiration を「No expiration」に設定
7. スコープで repo にチェック
8. Generate token → 表示されたトークンをコピー
